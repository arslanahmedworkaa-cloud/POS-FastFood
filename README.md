# BiteFlow POS

**Restaurant Point of Sale System for Pizza & Fast-Food Businesses**

BiteFlow POS is a Flutter-based point-of-sale application designed to help restaurants manage their daily operations, including business information, food categories, menu items, orders, billing, receipts, and sales reports.

Built with **Flutter, Dart, and Firebase**, it is designed for pizza shops, fast-food restaurants, and other food and beverage businesses.

## ✨ Features

### 🔐 User Authentication
- User login and registration.
- Firebase Authentication integration.

### 🏪 Business Management
- Add and manage business information.
- Save business name, email, phone number, address, and business image.

### 📂 Category Management
- Add, view, edit, and delete categories.
- Assign category IDs and names.
- Upload category images.

### 🍕 Food & Drink Item Management
- Add, view, edit, and delete menu items.
- Organize products for restaurant menus.
- Support different food and beverage categories, such as pizza, burgers, fries, hot drinks, cold drinks, and deals.

### 🛒 Order Management
- Manage restaurant orders and billing.
- Find and view existing orders.
- Print receipts and duplicate receipts.

### ❌ Order Cancellation
- Cancel individual items from an order.
- Print updated receipts after item cancellation.
- Cancel a complete order using the application's cancellation workflow.

### 🧾 Receipt Printing
- Print order receipts.
- Print duplicate receipts when required.
- Print updated receipts after item cancellations.

### 📊 Sales Reports
- Sales reports.
- Daily sales.
- Item-wise sales.
- Product-wise sales.

## 🛠️ Technologies Used

- **Flutter** — Application UI and development.
- **Dart** — Programming language.
- **Firebase Authentication** — User authentication.
- **Cloud Firestore** — Database.
- **Firebase Storage** — Storage integration.
- **Image Picker** — Selecting images from the device gallery.
- **PDF & Printing** — PDF generation and printing functionality.
- **FlutLab** — Cloud-based Flutter development environment.

## 🎯 Project Purpose

BiteFlow POS brings essential restaurant management tasks together in one application, helping organize menu management, order processing, billing, receipt printing, and sales reporting.
